칩업! 충북반도체고 챌린지 v1.3 휴대전화 설치 안내

1. GitHub 저장소 최상위에 이 폴더의 전체 파일을 올립니다.
2. Settings → Pages → Deploy from a branch를 선택합니다.
3. main / (root)를 선택하고 저장합니다.
4. 생성된 HTTPS 주소를 휴대전화에서 엽니다.

[Android]
Chrome → 앱 화면의 설치 버튼
또는 Chrome 메뉴(⋮) → 홈 화면에 추가 → 설치

[iPhone]
Safari → 공유 → 홈 화면에 추가 → 웹 앱으로 열기 → 추가

처음 한 번은 인터넷이 연결된 상태에서 실행해야 앱 파일이 저장됩니다.
