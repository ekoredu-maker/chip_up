칩업! 충북반도체고 챌린지 v1.2 GitHub Pages 설치형

1. 압축을 풉니다.
2. 폴더 안의 파일과 폴더 전체를 GitHub 저장소 최상위에 올립니다.
3. GitHub 저장소 Settings → Pages에서 main / (root)를 게시합니다.
4. 생성된 HTTPS 주소를 휴대전화에서 엽니다.
5. Android는 Chrome의 설치 또는 홈 화면에 추가를 사용합니다.
6. iPhone은 Safari의 공유 → 홈 화면에 추가를 사용합니다.

중요
- index.html만 올리지 말고 manifest.webmanifest, sw.js, icons 폴더, .nojekyll도 함께 올려야 합니다.
- 처음 한 번은 인터넷에 연결한 상태에서 실행합니다.
- 업데이트 후 이전 화면이 남아 있으면 브라우저를 완전히 닫고 다시 열거나 사이트 데이터를 새로 고칩니다.
