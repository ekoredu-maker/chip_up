📱 휴대전화에 설치하기

다운로드한 HTML 파일을 직접 여는 방식으로는 앱 설치와 오프라인 기능이 제한됩니다. 먼저 GitHub Pages 등 HTTPS 주소에 게시한 뒤 아래 방법으로 설치하세요.

Android · Chrome

  1. 게시된 앱 주소를 Chrome에서 엽니다.
  2. 화면의 설치 버튼을 누릅니다.
  3. 버튼이 보이지 않으면 Chrome의 ⋮ 메뉴 → 홈 화면에 추가 → 설치를 선택합니다.
  4. 홈 화면의 칩업 아이콘으로 실행합니다.

iPhone · Safari

  1. 게시된 앱 주소를 Safari에서 엽니다.
  2. 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 선택합니다.
  4. 웹 앱으로 열기를 켠 뒤 추가를 누릅니다.

설치 준비

  1. 압축파일의 내용을 GitHub Pages 같은 HTTPS 웹 공간에 올립니다.
  2. 휴대전화에서 게시 주소를 엽니다.
  3. 브라우저 메뉴에서 홈 화면 설치를 선택합니다.

설치 후 처음 한 번 온라인에서 실행하면 핵심 파일이 저장되어, 이후에는 인터넷 연결이 없어도 퀴즈를 이용할 수 있습니다.
