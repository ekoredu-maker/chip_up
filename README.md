# 칩업! 충북반도체고 챌린지 v1.4 (2027학년도 입학전형 맞춤판)

충북반도체고 입학 면접 및 직업능력평가 대비용 휴대전화 PWA입니다.

## v1.4 변경사항
- **📋 전형 탭 신설**: 2027학년도 시행 요강(안) 기준 일정(D-day), 일반/특별전형 배점(1차 400 + 2차 100), 모집 인원, 핵심 규칙, 면접 당일 체크리스트
- **🏁 2차 전형 실전 모의**: 직업능력평가 20문제·20분 → 40점 환산 → 이어서 모의면접 60점 → 2차 예상 100점
- **🎤 실전 모의면접 5문항**: 지원동기·학과·협업·직무·생활기록부 질문, 60초 답변, 면접태도·지원분야이해·구체성·인성협업 자가채점
- **문제 111개 추가 (총 431문제)**: 학과·직무 이해(제조/장비/케미컬·직무상식·기업산업), 입학전형 이해, 반도체 기초·안전·협업 상황판단
- **면접 질문 79개**: 39개 신규 + 기존 질문의 비어 있던 예시 답변 20개 보강, 꼬리질문, 그룹 필터, 30/45/60초 선택
- 서비스워커가 저장소에 없는 엑셀 파일을 캐시하려다 오프라인 설치가 실패하던 문제 수정
