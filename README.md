# 칩업! 충북반도체고 챌린지 v1.2

충북반도체고 입학 면접, 직업기초능력, 반도체 상식을 휴대전화에서 연습하는 오프라인 PWA입니다.

## GitHub Pages 게시

1. 이 폴더의 **내용 전체**를 GitHub 저장소 최상위에 업로드합니다.
2. 저장소의 `Settings → Pages`로 이동합니다.
3. `Source`를 `Deploy from a branch`로 선택합니다.
4. `main` 브랜치와 `/(root)`를 선택하고 저장합니다.
5. 생성된 HTTPS 주소를 휴대전화에서 엽니다.

## 휴대전화 설치

### Android · Chrome

- 앱 화면의 `설치` 버튼을 누릅니다.
- 설치 버튼이 보이지 않으면 `Chrome ⋮ → 홈 화면에 추가 → 설치`를 선택합니다.

### iPhone · Safari

- `공유 → 홈 화면에 추가 → 웹 앱으로 열기 → 추가` 순서로 설치합니다.

## 주요 파일

- `index.html`: GitHub Pages용 실제 앱
- `manifest.webmanifest`: 앱 이름·아이콘·실행 방식
- `sw.js`: 오프라인 캐시
- `icons/`: Android·iPhone 앱 아이콘
- `.nojekyll`: GitHub Pages 정적 파일 처리
- `칩업_문제은행_양식.xlsx`: 문제 추가 양식
- `source/칩업_싱글파일_v1.2_복구본.html`: 수정본을 복구한 단일 HTML 보관본
