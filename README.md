# 칩업! 충북반도체고 챌린지 v1.3.1

충북반도체고 입학 면접 및 직무적성검사 대비용 휴대전화 PWA입니다.

## v1.3.1 수정사항

- v1.3에서 누락된 `renderReview()` 함수를 복구했습니다.
- 화면 이동 시 오답노트 렌더링 오류로 퀴즈가 불러와지지 않던 문제를 해결했습니다.
- 렌더링 함수 하나에 문제가 생겨도 다른 기능이 멈추지 않도록 방어 처리를 추가했습니다.
- 서비스워커 캐시 이름을 `chipup-v1.3.1`로 변경하여 기존 오류 파일이 새 버전으로 교체되도록 했습니다.
- 320문제 및 직무적성 실전 20문제·15분 모드는 그대로 유지합니다.

## GitHub Pages 게시

1. 이 폴더 안의 파일과 `icons` 폴더를 저장소 최상위에 모두 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch → main → /(root)**를 선택합니다.
4. 생성된 HTTPS 주소를 휴대전화 Chrome에서 엽니다.
5. Chrome 메뉴의 **홈 화면에 추가/앱 설치**를 선택합니다.

## 기존 v1.3을 설치한 경우

새 파일 업로드 후 앱을 완전히 종료했다가 다시 실행하십시오. 여전히 이전 화면이면 Chrome에서 주소를 한 번 새로고침한 뒤 설치 앱을 다시 실행하십시오. 학습 기록 저장 키는 유지되므로 기존 기록은 그대로 이어집니다.
