## GitHub Pages 게시

1. 이 폴더 안의 파일과 `icons` 폴더를 저장소 최상위에 모두 업로드합니다.
2. GitHub 저장소의 `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. `main` 브랜치와 `/(root)`를 선택하고 저장합니다.
5. 생성된 HTTPS 주소를 휴대전화 Chrome 또는 Safari에서 엽니다.

## 휴대전화 설치

### Android
Chrome에서 앱 주소를 연 뒤 앱의 `설치` 버튼을 누릅니다. 버튼이 보이지 않으면 `⋮ → 홈 화면에 추가 → 설치`를 선택합니다.

### iPhone
Safari에서 앱 주소를 연 뒤 `공유 → 홈 화면에 추가 → 웹 앱으로 열기 → 추가`를 선택합니다.

## 주의

앱의 문제는 공식 기출문제가 아닙니다. 공개된 평가영역과 중학교 수준의 직업기초·반도체 개념을 바탕으로 만든 연습문제입니다.
